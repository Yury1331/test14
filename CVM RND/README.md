# CVM RND

Локальная папка в репозитории для диалогов и запросов по **CVM / «Безопасный город»**.

Сюда перенесены диалоги из ветки `cursor/vega-safe-city-a120` (каталог `dialogs/`, связанный с папкой `companies/vega/safe-city/`).

Облачный агент **не пишет** на диск компьютера (`C:\…\YandexDisk\…`). Чтобы получить папку у себя: скачайте файлы по ссылкам ниже и скопируйте в локальный каталог **CVM RND**.

## Скачать

Прямая ссылка: `https://github.com/Yury1331/test14/raw/<ветка>/<путь>`  
Пробелы в пути заменить на `%20`. Репозиторий публичный.

- **Вся папка:** https://github.com/Yury1331/test14/tree/cursor/cvm-rnd-7c09/CVM%20RND
- **ZIP всей ветки:** https://github.com/Yury1331/test14/archive/refs/heads/cursor/cvm-rnd-7c09.zip
- **Диалог «Вега» + БГ:** https://github.com/Yury1331/test14/raw/cursor/cvm-rnd-7c09/CVM%20RND/2026-07-23-vega-safe-city.md
- **Отчёт поиска по диалогам:** https://github.com/Yury1331/test14/raw/cursor/cvm-rnd-7c09/CVM%20RND/vega-dialog-search-report.md

После слияния в `main` в тех же URL замените `cursor/cvm-rnd-7c09` на `main`.
