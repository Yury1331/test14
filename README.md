# PocketBook — книга

Небольшой пример электронной книги в формате **FB2** для ридеров PocketBook.

## Файлы

| Файл | Описание |
|------|----------|
| `books/kniga.fb2` | Рассказ «Тихая страница» (русский язык) |

## Как загрузить на PocketBook

1. Подключите ридер к компьютеру по USB **или** отправьте файл по Wi‑Fi / через PocketBook Cloud.
2. Скопируйте `kniga.fb2` в папку `Books` на устройстве.
3. На ридере откройте **Библиотека** → выберите книгу → начните чтение.

### Альтернативные способы

- **PocketBook Cloud** — загрузите FB2 в облако с телефона или ПК, синхронизируйте на ридере.
- **Отправка на email** — если настроена функция Send-to-PocketBook, отправьте файл как вложение.
- **Карта памяти** — скопируйте файл на microSD и вставьте карту в ридер.

## Поддерживаемые форматы

PocketBook читает FB2, EPUB, PDF, TXT, MOBI и другие форматы без конвертации. Для русскоязычных книг удобнее всего **FB2** и **FB2.ZIP**.

## Редактирование

FB2 — это XML-файл в кодировке UTF-8. Его можно править в любом текстовом редакторе или собрать заново в Calibre / FictionBook Editor.
