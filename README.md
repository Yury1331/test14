# ЦКТ — Весовой поток

Демонстрационный лендинг компании **ООО «Цифровые Контрольные Технологии» (ЦКТ)** и продукта **АСУ ТП «Весовой поток»**.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8080
```

Затем перейдите на http://localhost:8080

## Содержание

- Hero с брендом ЦКТ и продуктом «Весовой поток»
- Описание модуля ЯРД 2.0 (авто / ж/д)
- Возможности автоматизации
- Экономический эффект
