# Камера видеонаблюдения цифровая 4BHNN0-0-0-0

> **Снято с КП.** В редакции 3 КП-2026-08-14-001 комплект пересчитан на камеры TRASSIR СТ-1. См. `cameras/trassir/`.

Артикул **4BHNN0-0-0-0** в открытых витринах TRASSIR / DSSL / GISP по прямому поиску **не найден**. По номенклатуре он совпадает с линейкой **ООО НИЦ «Технологии»** (Краснодар): «камера видеонаблюдения цифровая» + код платы/прошивки.

## Разбор артикула

По схеме НИЦ (разбор производителя на Хабре и каталоги 4BDNN / 4BBNN / 4MBNN / 2BNN):

| Часть | Значение |
|---|---|
| `4` | 4 Мп |
| `BH` | тип корпуса; ближайшие публичные линейки — корпусная BOX (`2BNN`, `*-BOX-*`) либо цилиндр (`BB` / `MB`) |
| `NN` | плата НИЦ + микропрограмма **Nexus** (реестр Минцифры №12466) |
| `0-0-0-0` | базовая комплектация в 1С (объектив / цвет / ИК / опции не зафиксированы в артикуле) |

Точный корпус, объектив и ИК **нужно подтвердить** у НИЦ или дилера по этому артикулу. Ниже — типовые ТТХ 4 Мп камер НИЦ с прошивкой Nexus, на которые ориентирован расчёт.
