# Производство и комплектующие

Модель: **TRASSIR TR-D6254 4.9–156**

## Где производится

| Аспект | Детали |
|---|---|
| Разработчик бренда | ООО «ДССЛ» (DSSL), Москва |
| Линейка | TREND (не СТ-1) |
| Сборка в РФ | Нет (по витринам дилеров; модель не маркируется (R) / (D)) |
| Сертификация СТ-1 / реестр РЭП | **Нет** у TR-D6254 |
| Актуальная замена со сборкой в РФ | TR-D6154IR10 v3 **(D)** — сборка в РФ; **(R)** — сертификат СТ-1 |

TR-D6254 — камера линейки TREND предыдущего поколения. Для госзакупок по ПП РФ №719 она не подходит. Если нужен реестр РЭП — смотреть **TR-D6154IR10 v3 (R)**.

## Известные комплектующие

Производитель **не публикует** полный перечень поставщиков. По спецификации:

| Узел | Характеристика |
|---|---|
| Матрица | 1/2.8" CMOS, 5 Мп (производитель не раскрывается) |
| Объектив | Моторизованный 4.9–156 мм, F1.35–F4.4, оптика ×32 |
| ИК-подсветка | Нет |
| PTZ-механизм | Скоростной привод до 500 °/с по пресету |
| Кодек / SoC | H.265+/H.265/H.264+/H.264, аппаратная IVS-аналитика |
| Корпус | Алюминий, IP67, IK10 |
| Питание | PoE+ 802.3at класс 4 / 24 В DC, до 16 Вт |
| Память | Слот microSD до 256 ГБ |
| Аудио | Внешние вход/выход 1/1, без встроенного микрофона и динамика |
| Прочее | Механический ИК-фильтр, грозозащита TVS 6000 V, тревожный вх/вых 2/1, RTC |
