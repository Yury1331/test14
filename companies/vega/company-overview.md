# Профиль компании

**Полное наименование:** АО «Концерн радиостроения „Вега“»  
**Холдинг:** Росэлектроника (Ростех)  
**Сайт:** https://vega.su/ (на момент сбора данных)

## История

- Корни — ЦКБ-17 (1944), разработка бортовых РЛС
- 1967 — Московский НИИ приборостроения
- 2003 — образован концерн «Вега»

## Направления деятельности

| Сегмент | Примеры |
|---|---|
| Оборонная продукция | РЛС, комплексы ДРЛО (А-50, А-50У, А-100) |
| Гражданская продукция | Системы видеонаблюдения и фотовидеофиксации, медтехника, УВД |
| Цифровая экономика | Комплексы для «умного города», дорожная фиксация ПДД |

## Опыт в видеофиксации (Россия)

По открытым данным, концерн устанавливал системы видеофиксации в:

- Иркутской области
- Тверской области
- Ульяновской области
