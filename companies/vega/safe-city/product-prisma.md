# Система «Призма»

Стационарный комплекс автоматической **фото- и видеофиксации нарушений ПДД**, разработанный концерном «Вега».

## Назначение

- Круглосуточная регистрация нарушений ПДД
- Распознавание государственных регистрационных знаков (ГРЗ)
- Автоматическое определение вида нарушения
- Формирование доказательной базы для ЦАФАП

## Технологии

- Обработка видеопотоков с **нейросетями** и глубоким обучением
- Измерение скорости **без радара** (по видеоаналитике)
- Низкое энергопотребление: **15–40 Вт** (в разных источниках — до 20 Вт для автономного комплекса)

## Ключевые преимущества (по заявлениям производителя)

| Параметр | Описание |
|---|---|
| Автономность | Работа от линий ночного освещения или **солнечных батарей** |
| Связь | GSM (LTE), MESH NET — без оптики |
| Монтаж | Заявлено ~25 минут на установку |
| Платформа | Linux, ARM |
| Масштаб | До 16 камер HD на внешний контроллер |
| Интеграция | Поддержка форматов постановлений, интеграция в базовые решения |
