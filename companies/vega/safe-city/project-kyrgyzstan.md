# Проект «Безопасный город» — Кыргызстан

## Хронология

| Дата | Событие |
|---|---|
| 04.09.2018 | Онлайн-аукцион Госкомитета ИТ и связи КР — победитель **Концерн «Вега»** (наименьшая цена по двум лотам) |
| 12.11.2018 | Подписание соглашения с Госкомитетом ИТ и связи КР |
| 2018–2019 | Развёртывание первой очереди в Бишкеке |
| 5 лет | Срок эксплуатации и передачи данных заказчику (по контракту) |

## Участники

| Организация | Роль |
|---|---|
| АО «Концерн радиостроения „Вега“» | Генподрядчик, система «Призма» |
| ООО «Швабе-Москва» | Техническая поддержка системы фиксации |
| ОсОО «Спец Проект Монтаж» (КР) | Проектирование, СМР |

Планировалось СП в Бишкеке с **≥40** местными специалистами на эксплуатацию.

## Объём первой очереди

По открытым данным:

| Тип | Количество |
|---|---|
| Скоростные рубежи (фиксация скорости) | 52 |
| Перекрёстки (сплошная, стоп-линия, красный свет) | 38 |
| Переносные комплексы фотофиксации | 20 |
| **Итого камер (первый этап)** | **~90** |

## География установки

- Бишкек (дороги города)
- Трасса Бишкек — Чалдовар
- Трасса Бишкек — Балыкчы
- Бишкек — аэропорт «Манас»
- Бишкек — КПП «Ак-Жол»

## Финансы (по СМИ)

- Предложение «Веги» на тендере: **~2,3 млрд сом** (около **$33 млн** по курсу 2018 г.)

## Функции системы

- Автоматическая фотовидеофиксация нарушений ПДД
- Интеллектуальное видеонаблюдение
- Передача данных о нарушениях государственному заказчику
- Эксплуатационная поддержка концерном
