# Dahua DH-CS4010-8ET-110

Облачный **smart-managed** настольный PoE-коммутатор. Аппаратный близнец неуправляемого [DH-PFS3010-8ET-96](../PFS3010-8ET-96/specs.md): те же 8 × 10/100 PoE + 2 × GE uplink, порт 1 до 90 Вт (802.3bt), Extend 250 м.

**Страница:** https://www.dahua.market/setevoye-oborudovaniye/dh-cs4010-8et-110  
**Datasheet:** https://www.dahuasecurity.com/la/products/All-Products/Transmission/Cloud-Managed-Switches/CS4010-8ET-110

## Отличие от PFS3010-8ET-96

| | PFS3010-8ET-96 | CS4010-8ET-110 |
|---|---|---|
| Управление | нет | веб, приложение, облако DoLynk Care |
| Бюджет PoE | 96 Вт | **110 Вт** |
| VLAN | нет | port-based, до 32 |
| PoE вкл/выкл, intelligent PoE | watchdog + DIP | watchdog + управление питанием с порта |
| Кнопка Reset | нет (DIP Default/Extend) | есть |
| Размеры | настольный ~190×100×30 мм | 190 × 106 × 30 мм |
