# Dahua DH-PFS3010-8ET-96

Неуправляемый настольный PoE-коммутатор: **8 × 10/100 PoE + 2 × GE uplink**, бюджет **96 Вт**, красный порт IEEE 802.3bt до 90 Вт.

**Официальная страница:** https://www.dahuasecurity.com/la/products/All-Products/Transmission/PoE-Switches/Desktop-PoE-Switch/PFS3010-8ET-96  
**Паспорт (V2.0):** http://material.dahuasecurity.com/uploads/cpq/prm-os-srv-res/smart/datasheetzipfiles/PFS3010-8ET-96_S0_datasheet_20231130.pdf

Управляемая замена той же схемы портов: [DH-CS4010-8ET-110](../CS4010-8ET-110/specs.md). Сравнение: [managed-analogs.md](managed-analogs.md).

## Основные характеристики

| Параметр | Значение |
|---|---|
| Тип | Неуправляемый L2, настольный |
| Порты PoE | 8 × RJ-45 10/100 Мбит/с |
| Uplink | 2 × RJ-45 10/100/1000 Мбит/с |
| SFP | нет |
| Бюджет PoE | **96 Вт** суммарно |
| Мощность на порт | порт 1 ≤ **90 Вт** (802.3bt / Hi-PoE); порты 2–8 ≤ 30 Вт |
| Стандарты PoE | IEEE 802.3af / at / Hi-PoE / **802.3bt** |
| Пины PoE | 8-pin: 1,2,4,5 (V+), 3,6,7,8 (V−) |
| Extend | до **250 м** (10 Мбит/с) |
| PoE Watchdog | да |
| Коммутационная способность | 5,60 Гбит/с |
| Пересылка | 4,17 Mpps |
| MAC | 8K |
| Буфер | 4 Мбит |
| Питание | **48–57 В DC** (внешний БП) |
| Потребление | простой 3 Вт / полная нагрузка 96 Вт |
| Температура | −10…+55 °C |
| Корпус | металл, без вентилятора |
| DIP | Default / Extend |
