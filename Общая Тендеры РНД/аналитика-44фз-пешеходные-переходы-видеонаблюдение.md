## Методика

1. Поиск в ЕИС по ключевым словам: *пешеходный переход*, *светофор*, *видеонаблюдение*, *фотовидеофиксация*, *комплекс автоматической фиксации*.
2. Фильтр: **44-ФЗ**, регион заказчика — Ростовская область (для блока РО).
3. Верификация по карточкам закупок на zakupki.gov.ru и агрегаторах (Synapse, TenderGuru, Rostender).
4. Для федеральной статистики — отраслевые обзоры анализа контрактов ЕИС (OnlineGIBDD, Тендерплан/RUБЕЖ).

> **Ограничение:** агрегаторы могут не показывать все закупки; для участия в тендерах ориентируйтесь на первичные документы в ЕИС.

> **Ростовская область в топ-5 по этому рейтингу не входит** — региональный дорожный видеоконтроль в РО развивается через **ГКУ «Центр БДД»**, а не через крупные лоты на передачу данных федерального масштаба.

#### Типовые предметы закупок (РФ)

1. **Поставка и монтаж** стационарных/мобильных комплексов фиксации.
2. **Услуги передачи данных** о нарушениях ПДД (стационарные + мобильные камеры).
3. **Модернизация** для фиксации дополнительных нарушений (ремень, телефон, полоса).
4. **Эксплуатация** систем «Безопасный город» / «Безопасный регион».
5. **Интеллектуальные модули** муниципального видеонаблюдения (пример: Новороссийск, **0118300013326000359**, 2026).

#### Отраслевой контекст

- Около **30%** комплексов фотовидеофиксации в РФ **устарели** и не фиксируют новые виды нарушений (OnlineGIBDD / ГК «Урбантех»).
- Государственная **Стратегия БДД** стимулирует проактивный подход: камеры у школ, детсадов, медучреждений.
- Камеры с **ИИ** (пример — МКАД): выявление ДТП, управление светофорами, розыск ТС.

#### Выводы для участия (РФ, видеонаблюдение)

1. **Рынок растёт** — приоритет не только поставке «железа», но и **связи, ПО, аналитике, ТО**.
2. **Крупные контракты** (>100 млн ₽) — у региональных центров БДД и операторов фиксации.
3. **Муниципальный сегмент** — «Безопасный город», школы, больницы; средний чек **0,3–10 млн ₽**.

### Требования для участия (типовые)

- Регистрация в ЕИС + аккредитация на ЭТП (РТС-тендер, Сбербанк-АСТ, Фабрикант и др.).
- КЭП (квалифицированная электронная подпись).
- Для строительных работ — **СРО**; для метрологии — аккредитация / лицензия.
- Обеспечение заявки: обычно **0,5–5%** НМЦК; по крупным лотам — до **10%**.
- Преимущество **СМП** (ст. 30 44-ФЗ) — актуально для муниципальных лотов РО.
