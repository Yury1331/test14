# test14 — ТЗ СВН ФБЛПУ «Санаторий «Радуга» ФНС России»

Каталог подготовлен для заказчика: техническое задание и спецификации на поставку оборудования и монтаж системы охранного видеонаблюдения.

**Объект:** 354008, Краснодарский край, г. Сочи, ул. Виноградная, д. 53 (верхняя зона) и ул. Пирогова, д. 46/6 (нижняя / пляжная зона).  
**Ориентир по объёму:** 105 уличных IP-камер 5 Мп, объектив 3,6 мм, видеосервер на 105 каналов.
